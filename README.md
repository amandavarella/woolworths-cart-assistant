# Woolworths Cart Assistant

A simple shopping list management tool for Woolworths grocery shopping.

## Features

- Shopping list management via text file
- Simple Python script for reading shopping lists

## Getting Started

1. Create a `.env` file (if needed for future features):
```bash
# Add any environment variables here
```

2. Add your shopping items to `shopping-list.txt` (one item per line)

3. Run the script:
```bash
python main.py
```

## Usage

### Shopping List

Edit `shopping-list.txt` to add or modify items. Each line should contain one product name:
```
a2 Milk Full Cream Milk 3L
Inside Out Almond Milk Unsweetened 1L
Devondale Shredded Mozzarella Cheese 600g
```

## Notes

- Shopping list items should be added manually to `shopping-list.txt`
- One item per line
